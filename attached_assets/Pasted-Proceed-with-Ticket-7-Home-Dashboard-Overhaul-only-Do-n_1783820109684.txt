==========================================
TICKET 7 — HOME DASHBOARD OVERHAUL
==================================

The goal of this ticket is to transform the Home page into a polished, modern, premium dashboard while preserving the GymMice design language.

---

1. Today's Workout

---

Move the existing "Today's Workout" card near the top of the Home page, immediately below the streak banner.

This should become the primary focus of the dashboard.

Improve the card by displaying:

* Workout name (Push / Pull / Legs)
* Target muscle groups
* Number of exercises
* Estimated workout duration
* Scheduled workout time (if available from the Schedule page)
* Large "Start Workout" button

Do not remove any existing workout functionality.

---

2. Next Event

---

Immediately below Today's Workout, add a "Next Event" card.

For now, automatically display the closest upcoming event from the Schedule page.

Display:

* Event title
* Category
* Date
* Time
* Countdown until the event starts
* Appropriate category icon

If no future event exists, display a friendly empty state such as:

"No upcoming events."

This section should already be prepared to work with future AI scheduling.

---

3. Today's Stats

---

Replace the existing Calories and Water cards with animated circular progress rings.

Display:

Calories:

* Current
* Goal
* Remaining

Water:

* Current
* Goal
* Remaining

Keep the Steps card, but animate it as well.

The Workout card can remain but improve its visual consistency.

---

4. Animations

---

Whenever the Home page opens:

Animate:

* Progress rings
* Step counter
* Numbers
* Progress values
* Graphs

Use smooth, premium animations.

5. Session Progress

---

Keep the current graph as a preview.

Add a "View Analytics" action.

---

6. Analytics Page

---

Create a dedicated analytics screen.

Display three sections or tabs:

* Push
* Pull
* Legs

Each section should contain multiple exercise progress charts.

Examples:

Push

* Bench Press
* Incline DB Press
* Shoulder Press
* Cable Fly
* Triceps Pushdown

Pull

* Pull Ups
* Lat Pulldown
* Barbell Row
* Cable Row
* Face Pull

Legs

* Squat
* Romanian Deadlift
* Leg Press
* Leg Extension
* Hamstring Curl

Each exercise should have its own progress graph.

The graphs should appear realistic.

Avoid perfectly straight progression.

Include:

* Plateaus
* Small regressions
* Personal record jumps
* Natural fluctuations

30s
