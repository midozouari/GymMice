TICKET 6 — ONBOARDING ENHANCEMENTS
==================================

The goal of this ticket is to improve the onboarding experience and prepare GymMice for future AI-powered workout generation.

## 1. Athlete Sport Selection

On the **"What describes you best?"** step:

When the user selects **Athlete**, dynamically display a searchable sport selector below the selected card.

Requirements:

* Search bar.
* Scrollable alphabetical list.
* At least **50+ organized sports**.
* Store the selected sport as `selectedSport`.
* Keep the selected sport when navigating back and forth.
* Only display this section when Athlete is selected.

## 2. Dream Physique Upload

On the **"Your Goal Physique"** step:

Add an OPTIONAL section below the physique goal selection:

**"Upload your dream physique (Optional)"**

Requirements:

* Pick an image from the gallery.
* Display a preview.
* Allow replacing the image.
* Allow removing the image.
* Store **only the image URI**, not the image itself.
* Handle permissions correctly.
* Do not make this step mandatory.

Use Expo Image Picker.

## 3. Persist Onboarding Data

This includes every onboarding field, including:

* Name
* Age
* Gender
* Height
* Weight
* Fitness level
* Fitness goal
* Chronic illnesses
* Selected profile type
* Selected sport (if Athlete)
* Dream physique image URI
* Any other onboarding values already collected

The purpose is simply to preserve onboarding progress and user preferences locally.

Do NOT create or connect a backend database.

Do NOT call any AI APIs.

Do NOT upload any data to a server.

Everything should remain local for the MVP.
